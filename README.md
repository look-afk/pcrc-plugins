# pcrc-plugins

Каталог плагинов PCRC. Статический сайт на GitHub Pages, без сервера и базы.

## Как это работает
1. Плагин — файл `plugins/<name>.py` (класс от `PluginBase`, как в `pcrc-client/plugins/_base.py`).
2. При каждом push/PR GitHub Actions запускает `tools/build_index.py`: проверяет файлы (код не выполняется), считает sha256 и собирает `site/index.json`.
3. Из ветки `main` сайт автоматически публикуется на Pages.
4. Пользователь копирует с сайта готовую команду `plugin_install <url> <sha256>`.

## Набор инструментов PCRC

- **Workflow Builder** (`wf_*`) — хранит пошаговые сценарии и экспортирует план. Не запускает команды автоматически.
- **Event Bus** (`event_*`) — локальный журнал событий до 200 записей. Это журнал для отладки, а не автоматическая межплагинная шина.
- **Command Studio** (`cs_*`) — сохраняет пресеты команд для проверки и ручного запуска; не выполняет их.
- **Plugin Developer Kit** (`pdk_*`) — выдаёт шаблон нового плагина и чек-лист публикации.
- **Plugin Audit** (`audit_*`) — статический анализ Python-кода по известным риск-маркерам. Это НЕ изолированная среда и не гарантия безопасности.
- **PC Benchmark** (`bench_*`) — короткий ограниченный CPU/память/временный диск micro-benchmark; результаты ориентировочные.
- **Smart Scheduler** (`sched_*`) — сохраняет напоминания и статусы в локальный JSON. Не запускает системные команды и не гарантирует фоновые уведомления.
- **App Blocker** (`ab_*`) — Windows-блоклист точных имён .exe и локальный System Guard. `ab_set_password` открывает на самом ПК окно настройки пароля (пароль хранится как PBKDF2-хеш, не отправляется в Telegram); `ab_system` показывает полноэкранное окно; разблокировка — вводом пароля. Аварийный локальный выход: `Ctrl+Shift+F12`. Оверлей не отключает диспетчер задач, системные способы восстановления или защиту Windows. Блоклист приложений включается отдельно через `ab_enable`, выключается через `ab_disable`.

Команды каждого плагина имеют префикс, чтобы не пересекаться с командами других расширений. В текущем API PCRC плагин получает только `handle(cmd, param)`, поэтому команды используют интерфейс Telegram. System Guard — локальное окно на ПК: пароль задаётся физически на компьютере, потому что API плагинов не передаёт достоверную роль отправителя команды.

## Добавить плагин
Fork → положить `plugins/<name>.py` → Pull Request. Проверка в PR покажет ошибки формата.
Требования: имя файла = `NAME`, строка `NAME = "…"` (один пробел вокруг `=`), `DESCRIPTION`, непустой `COMMANDS`, LF-переводы строк, до 200 КБ. Команды не должны совпадать со встроенными командами клиента (список в `tools/core_commands.txt`). Перед слиянием владелец читает код.

## Запуск проверки локально
    python tools/build_index.py
